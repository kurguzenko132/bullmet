# Bullmet — полная доработка личного кабинета

Что изменено:

- Личный кабинет `/account` стал полноценной страницей пользователя.
- Добавлены:
  - крупный приветственный блок;
  - статистика: корзина, заявки, заказы, избранное;
  - боковая навигация;
  - обзор с быстрыми действиями;
  - история заказов;
  - история заявок;
  - избранные товары;
  - редактирование профиля;
  - кнопка выхода;
  - переход в админку для администратора.
- Подключены данные:
  - текущая Supabase-сессия;
  - профиль из `profiles`;
  - заказы из `orders` по email пользователя;
  - заявки из `requests` по email пользователя;
  - избранное из Supabase `favorites` и localStorage;
  - корзина из localStorage.
- В схему добавлено поле `profiles.phone`.
