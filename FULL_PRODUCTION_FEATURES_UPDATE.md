## Bullmet: Полная реализация этапов — обновление

Этот релиз объединяет несколько крупных улучшений, направленных на превращение сайта Bullmet из каталога в полноценный интернет‑магазин:

### Многошаговое оформление заказа

- Компонент `CheckoutContents` переработан в двуступенчатый процесс. Сначала покупатель вводит личные данные и выбирает способ доставки, затем на втором шаге подтверждает данные и видит итоговую сумму.
- Для навигации добавлены кнопки **«Далее»**, **«Назад»** и **«Оформить заказ»**. После отправки формы заказ сохраняется и пользователь видит сообщение об успехе, как и раньше.
- Стейт покупателя сохраняется в `customerData`, что упрощает добавление новых полей в будущем.

### Быстрая смена статусов заказов

- В админ‑панели заказов (`AdminOrdersPage`) добавлена кнопка **«Следующий статус»** рядом с селектом статусов. Она помогает менеджеру быстро переводить заказ по воронке: от «Новый» к «В обработке», далее к «Ожидает оплаты» и так далее по кругу.
- Функция `getNextStatus` определяет следующий статус, основываясь на массиве `ORDER_STATUSES`.

### Подготовка фото для каталога

- Все фотографии товаров из архива пользователя автоматически обработаны и разделены на три цветовые категории: **black**, **grey**, **white**.
- Каждое изображение помещено на квадратный фон соответствующего цвета и сохранено в каталоге `public/assets/products_{color}`. Это обеспечивает единообразие и готовность к загрузке в Supabase.

### Дополнительные стили

- В `globals.css` добавлены стили для многошагового чекаута: блок навигации (`.checkoutNav`) и обёртка для шага подтверждения (`.checkoutConfirmation`).
- Эти стили обеспечивают корректное расположение кнопок и элементов на обеих стадиях оформления.

### Как протестировать

1. Установите зависимости и соберите проект:
   ```bash
   pnpm install
   pnpm build
   pnpm dev
   ```
2. Перейдите на страницу **/checkout** после добавления товаров в корзину, чтобы увидеть новый двухшаговый процесс оформления.
3. В админке откройте **«Заказы»** и попробуйте кнопку «Следующий статус» для разных заказов.
4. Новый набор подготовленных изображений находится в папках `public/assets/products_black`, `products_grey`, `products_white` — при желании их можно загрузить в хранилище Supabase для рабочих товаров.

### Что дальше

- Эти улучшения закладывают основу для следующих этапов: расширения карточки товара (360°‑просмотр, отзывы с фото), интеграции методов оплаты (Apple Pay, Google Pay), системы отзывов и рейтингов, маркетинговых рекомендаций и SEO‑оптимизации.
