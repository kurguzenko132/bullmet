# Bullmet — этап 4: заказы и заявки как мини-CRM

Что добавлено:
- Расширены статусы заказов:
  - Новый
  - В работе
  - Ожидает оплаты
  - Оплачен
  - Передан в доставку
  - Выполнен
  - Отменён
- Для заказов и заявок добавлены CRM-поля:
  - priority
  - follow_up_at
  - manager
- В админке заказов добавлены:
  - CRM-воронка статусов
  - быстрый выбор приоритета
  - ответственный менеджер
  - дата/время напоминания
  - быстрые действия: звонок, Telegram, Email
  - история обработки в карточке заказа
  - расширенная статистика
- В админке заявок добавлены:
  - CRM-воронка статусов
  - быстрый выбор приоритета
  - ответственный менеджер
  - дата/время напоминания
  - быстрые действия: звонок, Telegram, Email
  - история обработки в карточке заявки
  - расширенная статистика
- API обновления заказов и заявок теперь пишет изменения в `admin_activity_log`.
- Добавлен SQL-файл `database/admin-orders-requests-crm.sql`.
- Проверка `npx tsc --noEmit` прошла успешно.

Важно:
- Для существующей базы выполнить `database/admin-orders-requests-crm.sql`.
- Если ранее не выполнялся SQL этапа 1, сначала выполнить `database/admin-foundation-site-control.sql`, потому что там создаётся `admin_activity_log`.
