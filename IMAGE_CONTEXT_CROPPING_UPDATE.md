# Bullmet — отдельное кадрирование фото по зонам сайта

Теперь у каждого фото товара настройки отображения разделены по контекстам:

- `catalog` — карточка в каталоге
- `product` — главное фото на странице товара
- `thumb` — миниатюры галереи
- `variant` — миниатюры вариантов цвета/исполнения
- `related` — похожие товары
- `modal` — большое фото в просмотрщике
- `home` — карточки/ленты на главной странице

Для каждого контекста можно отдельно настроить:

- режим: `cover` или `contain`
- zoom
- позицию X
- позицию Y

Настройки хранятся в поле `image_settings` таблицы `products`.
