# Bullmet — production flow update

Добавлен следующий этап публичной части сайта без изменений админки:

- реальное оформление заказа из корзины через `/api/orders`;
- сохранение заказа в `public.orders`;
- Telegram-уведомления по новым заказам;
- рабочая заявка “Купить в 1 клик” через `/api/requests`;
- рабочая форма контактов;
- рабочая форма услуг с загрузкой файлов в bucket `request-files`;
- реальный счетчик корзины в шапке;
- поисковое окно в шапке;
- API поиска товаров `/api/products/search`;
- рабочие фильтры, поиск, сортировка и вид “плитка/список” в каталоге;
- добавление товара в корзину прямо из каталога.

Новые env-переменные:

```env
SUPABASE_SERVICE_ROLE_KEY=...
NEXT_PUBLIC_SUPABASE_REQUEST_FILES_BUCKET=request-files
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_IDS=123456789,987654321
```

Для локального запуска реальные секреты хранить только в `.env.local`.
