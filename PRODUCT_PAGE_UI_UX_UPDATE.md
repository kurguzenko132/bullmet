# Bullmet — обновление карточки товара

Что изменено:

- Главное фото товара и фото в модальном просмотре больше не обрезаются контейнером: используется `contain`, центрирование и ограничение по ширине/высоте.
- Миниатюры, варианты цвета и похожие товары также отображают изображения без грубой обрезки.
- Убраны табы `Описание / Характеристики / Доставка / Отзывы`.
- Вместо табов добавлены простые последовательные блоки: `О товаре`, `Характеристики`, `Доставка и оплата`, `Отзывы`.
- Модалка просмотра фото стала аккуратнее: затемненный фон, фото по центру, миниатюры снизу, без белых пустых полос.
- Похожие товары теперь показываются с фото в режиме `contain`, чтобы часы и декоративные изделия не резались.

Важно:

Если сама фотография в базе уже является сильным крупным планом, сайт не сможет показать полный товар — нужно загрузить нормальное фото товара целиком. Но теперь верстка не будет дополнительно обрезать изображение.
