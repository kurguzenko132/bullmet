# Обновление карточки товара: варианты цвета через фото

## Что изменено

- В блоке **Цвет / вариант** на странице товара вместо круглых маркеров теперь показываются миниатюры реальных фотографий товара.
- Активный вариант подсвечивается оранжевой рамкой и подписью **Сейчас выбран**.
- Неактивные варианты ведут на соответствующую карточку товара.
- Миниатюра берется из первого фото товара: `image` / `images[0]`.
- Учитываются настройки отображения фото из админки: `catalog_image_fit`, `catalog_image_position`, `product_image_fit`, `product_image_position`.
- В админке в блоке группы цвета варианты теперь тоже показываются с миниатюрой товара, а не только с цветовым кружком.

## Как правильно создавать цветовые варианты

1. Создайте отдельный товар для каждого цвета/варианта.
2. Укажите одинаковый `color_group_id` у всех вариантов одной модели.
3. У каждого товара заполните `color_name` — например: `Черный`, `Белый`, `Серый`.
4. Первое фото товара должно соответствовать его цвету, потому что именно оно будет использоваться в переключателе вариантов.

## Пример

- `chasy-volna-black` → color_group_id: `chasy-volna`, color_name: `Черный`
- `chasy-volna-white` → color_group_id: `chasy-volna`, color_name: `Белый`

На странице товара пользователь увидит две карточки-варианта с фото, а не абстрактные кружки.
