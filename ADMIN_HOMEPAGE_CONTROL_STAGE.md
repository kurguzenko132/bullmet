# Bullmet — этап 2: управление главной страницей из админки

Что добавлено:
- Новый раздел `/admin/homepage` для управления главной страницей.
- Новый файл `lib/homepageControl.ts` с дефолтными настройками главной.
- Новый публичный API `/api/homepage-control`.
- Новый админский API `/api/admin/homepage-control`.
- Главная страница `/` теперь читает настройки главной из Supabase `site_settings` по ключу `homepage_control`.
- Если данных нет в Supabase, главная использует безопасные дефолтные значения.
- В админке можно управлять:
  - hero-блоком;
  - строкой преимуществ;
  - главными переходами;
  - блоком популярных товаров;
  - производственным блоком;
  - шагами “Как мы работаем”;
  - галереей производства;
  - финальным CTA.
- Можно включать/выключать блоки и карточки.
- Можно менять тексты, ссылки, изображения и порядок.
- Добавлен SQL-файл `database/admin-homepage-control.sql`.
- Проверка `npx tsc --noEmit` прошла успешно.

Важно:
- Для существующей базы выполнить SQL `database/admin-homepage-control.sql`.
- После сохранения в `/admin/homepage` публичная главная начнёт брать данные из Supabase.
