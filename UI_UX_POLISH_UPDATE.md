# UI/UX polish update

Что улучшено:

- увеличены высоты карточек товаров и услуг, чтобы изображения не выглядели сплюснутыми;
- выровнены отступы секций на главной странице;
- улучшены карточки товаров: больше воздуха, крупнее цена, аккуратнее кнопка корзины;
- улучшены карточки услуг резки;
- каталог получил более гибкую сетку `auto-fill`, чтобы карточки не ломали композицию при разном количестве товаров;
- увеличены изображения в каталоге;
- улучшена карточка товара: крупнее главное фото, больше воздуха, стабильнее сетка;
- улучшены информационные блоки, галерея, процесс работы и CTA;
- поправлено центрирование иконок в хедере;
- улучшен адаптив для планшетов и телефонов.

Обновление: скопировать содержимое архива поверх текущего проекта, затем `git add . && git commit && git push`.
