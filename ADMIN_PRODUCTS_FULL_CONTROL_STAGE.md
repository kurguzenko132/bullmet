# Bullmet — этап 3: управление товарами и фото

Что добавлено:
- Раздел `/admin/products` теперь грузит все товары, включая черновики и скрытые.
- Добавлены расширенные статусы товара:
  - active — опубликован
  - draft — черновик
  - hidden — скрыт
  - out_of_stock — нет в наличии
- Публичный каталог не показывает draft и hidden.
- В админке добавлена панель диагностики товаров:
  - опубликовано
  - черновиков
  - скрыто
  - без фото
  - слабое описание
  - без цены
- В форму товара добавлены:
  - SEO title
  - SEO description
  - sort_order
  - расширенный статус
- В списке товаров добавлены:
  - фильтр по статусу
  - быстрый переход на товар
  - быстро скрыть/опубликовать
  - редактировать
  - дублировать
  - удалить
- Сохранение товара теперь пишет SEO, сортировку и расширенный статус в Supabase.
- Добавлена SQL-миграция `database/admin-products-full-control.sql`.
- Проверка `npx tsc --noEmit` прошла успешно.

Важно:
- Для существующей Supabase базы выполнить `database/admin-products-full-control.sql`.
- После этого статусы hidden/out_of_stock и SEO-поля будут сохраняться корректно.
