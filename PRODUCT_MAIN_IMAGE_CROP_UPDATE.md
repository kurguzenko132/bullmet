# Исправление настройки главного фото товара

Что изменено:

- Главное фото на странице товара теперь по умолчанию использует режим `contain` / «Показать целиком», чтобы фото не обрезалось.
- В админке у выбранной фотографии появились две явные кнопки:
  - «Настроить главное фото товара»
  - «Настроить фото для каталога»
- В модалке настройка `Страница товара` переименована в `Главное фото товара`.
- Добавлена кнопка «Показать главное фото целиком», которая сбрасывает кадр главного фото на безопасное отображение без обрезки.

Важно: если у товара уже были сохранены старые настройки кадра с режимом «Заполнить область», открой товар в админке → выбери нужное фото → «Настроить главное фото товара» → нажми «Показать главное фото целиком» → сохрани товар.
