# Важные исправления этой сборки

## 1. Старое фото главной больше не должно мигать при жестком обновлении
Главная страница больше не берет старые настройки из `localStorage`, если подключен Supabase. До загрузки настроек показывается нейтральный skeleton-блок, а затем актуальная картинка из `site_settings`.

## 2. Демо-товары не возвращаются из кода
Каталог и главная не используют демо-товары как fallback. Если в Supabase товаров нет, показывается пустое состояние.

Если старые товары уже есть в Supabase, один раз выполни:

```sql
-- database/cleanup-demo-data.sql
```

## 3. Настройка фото товара вынесена в модальное окно
В админке товара теперь компактный блок с двумя превью и кнопкой `Настроить кадр`. Большая настройка открывается в модальном окне.

## 4. Перетаскивание фото исправлено
Фото можно менять местами мышкой или пальцем. Первая фотография становится основной.

## 5. SQL старых архивов больше не использовать
Используй только актуальный `database/supabase-schema.sql`. В нем нет insert-заглушек для товаров и главной страницы.
