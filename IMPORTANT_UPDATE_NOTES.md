# Важное обновление Bullmet

## Что исправлено

- Полный SQL больше не добавляет демо-товары обратно.
- Полный SQL больше не восстанавливает старую заглушку главного экрана.
- Каталог и главная больше не показывают демо-товары во время загрузки Supabase.
- Если Supabase подключен, но товары удалены, каталог останется пустым до добавления новых товаров.
- Главное фото в админке больше не должно мигать старой заглушкой, если настройки уже сохранены в localStorage/Supabase.
- Для каждого фото товара добавлены отдельные настройки отображения.
- Фото можно сортировать перетаскиванием мышкой или пальцем.
- Настройка кадра теперь не через “верх/низ”, а через живое превью: можно двигать точку на фото и сразу видеть результат.

## Как правильно обновить базу

В Supabase выполняй новый файл:

`database/supabase-schema.sql`

Он безопасный: не вставляет демо-товары и не возвращает старую главную картинку.

Если старые демо-товары уже вернулись после старого SQL, один раз выполни:

`database/cleanup-demo-data.sql`

Он удалит только старые демо-slug товары.

## Важно

Не используй старые архивы и старый SQL, потому что именно они могли возвращать заглушки и демо-товары.
