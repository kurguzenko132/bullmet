# Bullmet — отзывы без модерации + фото

Что изменено:
- Отзывы на карточке товара теперь создаются со статусом `published`.
- Сообщение формы больше не говорит про модерацию.
- Кнопка стала “Опубликовать отзыв”.
- После отправки отзыв сразу добавляется в список на странице товара.
- В форме отзыва добавлена загрузка фото: до 5 изображений.
- Фото загружаются в Supabase Storage bucket `product-images` в папку `reviews/...`.
- Админ-страница отзывов обновлена: модерация отключена, при необходимости отзыв можно скрыть вручную через Supabase статусом `hidden`.
- Добавлен SQL-файл `database/reviews-auto-publish-photos.sql` для существующей базы Supabase.
- Проверки `npx tsc --noEmit` и `npm run build` прошли успешно.

Важно для существующей базы:
- Выполнить SQL из `database/reviews-auto-publish-photos.sql` в Supabase SQL Editor.
- Убедиться, что Storage bucket `product-images` публичный и разрешает insert.
