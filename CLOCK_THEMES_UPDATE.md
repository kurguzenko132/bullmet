# Тематики часов

Добавлено отдельное поле `clockTheme` / `clock_theme` для товаров категории «Часы собственного производства».

Тематики:
- Авто-мир
- Барбер
- Парилка
- Детские
- Кухонные
- Классика
- Медицина
- Музыка
- Парикмахерская
- Природа
- Ремонт и стройка
- Романтика
- Рукоделие и ремесло
- Рыбалка
- Животные
- Спорт

После обновления проекта выполните свежий SQL:

```sql
-- database/supabase-schema.sql
```

В админке поле появляется только для категории «Часы собственного производства». В каталоге добавлен фильтр «Тематика часов».
