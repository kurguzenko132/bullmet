# Обновление: отзывы, модерация и фото

Что добавлено:

- Страница админки `/admin/reviews`.
- Раздел "Отзывы" теперь активен в меню админки.
- Новые отзывы получают статус `pending` и не показываются на сайте до публикации.
- Админ может опубликовать, скрыть или удалить отзыв.
- Пользователь может приложить до 5 фото к отзыву.
- Фото отзывов загружаются в Supabase Storage bucket `product-images` в папку `reviews/`.
- В каталоге и карточке товара учитываются только опубликованные отзывы.

После обновления нужно выполнить SQL из `database/supabase-schema.sql`, чтобы добавить поля:

- `product_reviews.photo_urls`
- `product_reviews.status`

Важно: старые отзывы после SQL могут получить статус `pending`, если в таблице ранее не было поля `status`. Их можно будет опубликовать через `/admin/reviews`.
