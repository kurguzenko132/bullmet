# Catalog mobile UI + reviews update

## Что изменено

- На мобильной версии каталога фильтры теперь можно свернуть/развернуть.
- Карточки каталога на телефоне сделаны сеткой в 2 колонки в стиле маркетплейса.
- Кнопка корзины на мобильной карточке стала круглой и заметной.
- В карточках каталога добавлен блок рейтинга.
- На странице товара добавлен раздел отзывов и оценок.
- Оставлять отзывы могут только пользователи, которые вошли в аккаунт.

## Supabase

Добавлена таблица `product_reviews`.
После обновления проекта выполните `database/supabase-schema.sql` в Supabase SQL Editor.
