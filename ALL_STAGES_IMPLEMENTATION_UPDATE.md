# Bullmet — реализация ключевых этапов развития магазина

## Что вошло в релиз

### 1. Поиск и каталог
- В шапку сайта добавлена раскрывающаяся панель поиска.
- Поиск показывает быстрые подсказки по товарам.
- Переход по поиску ведёт в `/catalog?search=...`.
- Каталог теперь учитывает параметр `search` / `q` и фильтрует товары по названию, описанию, категории, материалу, цвету и тематике.

### 2. Карточка товара
- Добавлен zoom-просмотр фото товара.
- В карточку добавлен блок доверия: срок изготовления, гарантия, доставка.
- Добавлены кнопки шаринга товара: копирование ссылки, Telegram, WhatsApp.
- Добавлен FAQ-блок перед покупкой.
- Сохранена мобильная липкая кнопка покупки.
- Добавлена JSON-LD Product-разметка для SEO.

### 3. Быстрый заказ
- Модальное окно «Купить в 1 клик» переведено в `createPortal(document.body)`.
- При открытии модального окна блокируется прокрутка страницы.
- Повышен `z-index`, чтобы окно не конфликтовало с карточками, sticky-барами и анимациями.
- Добавлена отправка события аналитики `quick_order_submit`.

### 4. Корзина
- Добавлен блок рекомендаций / upsell «Можно добавить к заказу».
- Корзина слушает событие `bullmet-cart-updated`, поэтому обновляется после добавления товара.
- Добавление товара теперь отправляет событие аналитики `add_to_cart`.

### 5. Оформление заказа
- Оформление заказа стало двухшаговым:
  1. Контакты, доставка, оплата, комментарий.
  2. Подтверждение данных и состава заказа.
- Добавлен индикатор прогресса.
- Добавлены варианты оплаты: после согласования, при получении, по счёту.
- После оформления заказа пользователь видит ссылку на проверку статуса заказа.
- Отправка заказа пишет событие аналитики `checkout_submit`.

### 6. Статус заказа
- Добавлена публичная страница `/order-status`.
- Покупатель может проверить заказ по номеру и телефону.
- Отображаются статус, дата, состав заказа, сумма и комментарий менеджера.

### 7. Админка заказов
- В `/admin/orders` добавлена кнопка «Следующий статус».
- Менеджер может быстрее переводить заказ по этапам обработки.

### 8. Главная админки
- Графики в KPI-карточках больше не являются муляжом.
- Они строятся по реальным данным за последние 7 дней: заказы, выручка, заявки, отзывы.
- Для товаров и проблемных товаров используется реальная текущая величина, а не декоративная кривая.

### 9. Системные настройки
- `/admin/settings` теперь отдельная страница «Системные настройки», а не дубль «Контент сайта».
- Добавлены настройки: режим сайта, режим заказов, валюта, город, текст доставки, текст гарантии, переключатели наличия, отзывов и быстрого заказа.
- Добавлена проверка интеграций Supabase / Telegram / подготовленных фото.

### 10. Фото товаров
- Подготовленные изображения добавлены прямо в проект:
  - `public/assets/products_black`
  - `public/assets/products_grey`
  - `public/assets/products_white`
- Добавлен манифест `public/assets/prepared-products-manifest.json`.
- Добавлен TypeScript-экспорт `lib/preparedProductImages.ts`.

### 11. PWA / мобильная база
- Добавлен `app/manifest.ts`.
- В `layout.tsx` подключён manifest.
- Сайт готов к дальнейшему развитию в сторону PWA.

### 12. UI фиксы
- Карточки товаров и услуг на главной выровнены через flex-layout.
- Цена/кнопки в карточках закреплены внизу.
- Случайные скругления карточек убраны, чтобы стиль совпадал с геометричным дизайном Bullmet.
- Добавлены стили для поиска, статуса заказа, FAQ, zoom, checkout progress, upsell и системных настроек.

## Проверка после обновления

```bash
pnpm install
pnpm build
pnpm dev
```

Проверить страницы:
- `/` — карточки товаров/услуг на одном уровне.
- `/catalog?search=часы` — поиск по каталогу.
- `/catalog/[slug]` — zoom, FAQ, trust-блок, шаринг, sticky-покупка.
- `/cart` — upsell-блок.
- `/checkout` — двухшаговое оформление.
- `/order-status` — проверка заказа по номеру и телефону.
- `/admin` — реальные графики.
- `/admin/orders` — кнопка «Следующий статус».
- `/admin/settings` — отдельные системные настройки.
