# Обновление: админка контента и настройки сайта

Добавлен новый раздел админки:

- `/admin/content` — контент сайта
- `/admin/settings` — настройки сайта

Что можно редактировать без кода:

- подпись под логотипом;
- текст в footer;
- заголовок и описание главного экрана;
- тексты кнопок главного экрана;
- телефон, email, адрес, время работы;
- ссылки Telegram / WhatsApp / Instagram;
- короткие тексты для страниц Производство / Услуги / О компании / Контакты;
- FAQ.

Данные сохраняются в таблицу `site_settings` в Supabase с ключом `content`.
Если Supabase временно недоступен, настройки сохраняются в localStorage, чтобы админка не ломалась.

SQL выполнять не нужно, если таблица `site_settings` уже создана прошлым SQL.
