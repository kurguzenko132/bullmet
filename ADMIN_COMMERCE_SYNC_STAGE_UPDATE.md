# Bullmet — следующий этап: стабилизация админки заказов и заявок

Что изменено:

- Добавлены GET API для ручного обновления админки:
  - `/api/admin/orders`
  - `/api/admin/requests`
- На страницах `/admin/orders` и `/admin/requests` добавлена кнопка ручного обновления.
- Добавлен блок синхронизации Supabase: админ видит, подключена ли база и когда последний раз обновлялись данные.
- Улучшены пустые состояния: если заказов/заявок нет или Supabase не подключен, админка объясняет причину.
- Улучшен поиск заказов: теперь ищет по номеру, клиенту, телефону, email, товару и комментарию.
- Улучшен поиск заявок: ищет по клиенту, телефону, товару, комментарию и ID.
- Добавлены безопасные fallback-обновления статусов: если колонка `admin_note` не готова, статус всё равно может сохраниться.
- TypeScript-проверка `npx tsc --noEmit` пройдена.
