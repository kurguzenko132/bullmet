# Bullmet — фильтрация категорий с главной

Исправлена логика перехода с карточек категорий на главной странице.

Что изменено:
- карточка «Часы собственного производства» теперь ведёт в `/catalog?category=Часы собственного производства`;
- карточка «Садовые качели» теперь ведёт в `/catalog?category=Садовые качели`;
- если в Supabase/локальных настройках старые ссылки были сохранены как `/catalog`, они автоматически нормализуются для `clock` и `swing`;
- заголовок каталога теперь показывает активную категорию, например «Садовые качели» или «Часы собственного производства».

Проверить:
- главная → карточка «Садовые качели»;
- главная → карточка «Часы собственного производства»;
- каталог должен показывать только выбранную категорию.
