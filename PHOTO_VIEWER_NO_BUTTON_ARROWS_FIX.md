# Bullmet — исправление стрелок просмотра фото

Стрелки модалки фото полностью вынесены из button-элементов и переведены на независимые `div`-элементы с классами `bullmetPhotoViewer__arrow`.

Причина: глобальные/старые CSS-правила для `button` могли перебивать позиционирование стрелок и поднимать их вверх.

Что сделано:
- создана новая независимая модалка `bullmetPhotoViewer`;
- стрелки больше не являются `<button>` и не попадают под старые правила кнопок;
- стрелки позиционируются по центру слева/справа;
- крестик закрытия отдельно сверху справа;
- на мобильной версии стрелки скрыты, работает свайп.
