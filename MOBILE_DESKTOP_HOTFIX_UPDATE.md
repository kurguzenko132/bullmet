# Bullmet — mobile/desktop hotfix

Исправления по скриншотам:

- Нижняя мобильная навигация: пункт «Избранное» теперь ведёт на отдельную страницу `/favorites`, а не открывает личный кабинет.
- Мобильная CTA-кнопка «Заказать расчет» скрыта на страницах, где она мешала: корзина, checkout, личный кабинет, избранное, карточка товара, login/register.
- Корзина: блок рекомендаций больше не показывается в пустой корзине. Для непустой корзины карточки рекомендаций больше не сжимаются в узкие колонки.
- Карточка товара: скрыт ошибочный нижний ценник/дублирующая кнопка на desktop.
- Страница контактов: hero-заголовок ограничен по ширине и размеру, больше не залезает на изображение.
- Личный кабинет на мобильном: убран конфликт с фиксированной CTA-кнопкой, вкладки сделаны горизонтальными, кнопки профиля не перекрываются нижним меню.

Проверить после деплоя:

- `/cart` на мобильном — пустая корзина без сломанных рекомендаций.
- Нижнее меню — «Избранное» открывает `/favorites`.
- `/account` на мобильном — нет перекрытия кнопкой «Заказать расчет».
- `/catalog/[slug]` на desktop — нет странного ценника снизу.
- `/contacts` на desktop — заголовок не перекрывает изображение.
