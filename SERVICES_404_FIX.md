# Bullmet — исправление 404 на странице услуг

Что сделано:
- Страница `/services` больше не отдаёт 404, даже если услуги пока скрыты в настройках запуска.
- Если услуги скрыты, страница открывается как информационная страница.
- Показывается мягкое уведомление: основной запуск — часы, услуги доступны как направление для заявки.
- Все карточки услуг показываются, чтобы клиент видел возможности Bullmet.
- Header уже ведёт на `/services`, теперь ссылка рабочая.

SQL не требуется.
