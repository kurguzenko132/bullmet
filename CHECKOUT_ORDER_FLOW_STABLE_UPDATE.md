# Bullmet — стабилизация корзины и оформления заказа

Что изменено:

- Корзина `/cart` стала устойчивее к проблемам Supabase-профиля.
- Email пользователя теперь подставляется из локального входа, даже если Supabase-сессия подтянулась не сразу.
- После оформления заказ сохраняется не только в `sessionStorage`, но и в `localStorage`:
  - `bullmet_last_order`;
  - `bullmet_local_orders`.
- Личный кабинет показывает локально оформленные заказы сразу, даже если Supabase временно не вернул таблицу `orders`.
- `/order-success` умеет восстанавливать данные заказа из `sessionStorage`, `localStorage` и локальной истории заказов.
- API `/api/orders` больше не блокирует пользователя, если Supabase не сохранил заказ: заказ всё равно принимается, отправляется в Telegram и показывается на странице успеха с предупреждением.
