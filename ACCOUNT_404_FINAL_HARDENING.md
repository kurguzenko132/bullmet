# Bullmet — финальное усиление входа и 404 аккаунта

Исправления:

- Редирект после входа теперь жестко нормализует `next`.
- Любые старые ссылки `/profile`, `/cabinet`, `/lk` ведут в `/account`.
- Любые вложенные пути `/account/...` ведут в `/account`.
- Добавлен fallback `/auth/callback`, чтобы Supabase redirect URL не давал 404.
- После входа используется безопасный `window.location.href` на проверенный маршрут.
