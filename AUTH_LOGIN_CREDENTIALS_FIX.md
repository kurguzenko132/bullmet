# Bullmet — улучшение входа в аккаунт

Исправлено поведение формы входа при ошибке Supabase `Invalid login credentials`.

Что сделано:
- сырая английская ошибка заменена на понятный русский текст;
- если пользователь пытается войти в несуществующий клиентский аккаунт, показывается кнопка “Создать аккаунт с этим email”;
- для входа в админку добавлено понятное объяснение: пользователь должен быть создан в Supabase Auth, а email должен совпадать с `NEXT_PUBLIC_ADMIN_EMAIL` или `NEXT_PUBLIC_ADMIN_EMAILS`;
- текст страницы входа обновлён под запуск с часами.

Важно:
- код не может сам создать админа в Supabase; админ-пользователя нужно создать в Supabase Dashboard → Authentication → Users → Add user.
