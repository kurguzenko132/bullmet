# Bullmet — вход администратора и горизонтальный скролл

Что исправлено:
- Если администратор входит через обычную страницу `/login` без параметра `next`, после успешного входа он автоматически попадает в `/admin`.
- Если пользователь не администратор, обычный вход по-прежнему ведёт в `/account`.
- Если вход был открыт через `/login?next=/admin`, переход в админку сохраняется.
- В админке убран горизонтальный скролл по X:
  - добавлены `min-width: 0` и `max-width: 100%` для основных сеток;
  - ограничены ширины topbar, таблиц, графиков и карточек;
  - добавлен `overflow-x: hidden` для админского workspace.
- Проверка `npx tsc --noEmit` прошла успешно.
