# Bullmet — быстрый заказ и улучшенные заявки

## Что добавлено

- Кнопка **“Купить в 1 клик”** на странице товара.
- Кнопка **“Купить в 1 клик”** в карточках каталога.
- Модальное окно быстрого заказа:
  - имя;
  - телефон;
  - город;
  - размер / вариант;
  - количество;
  - удобный способ связи;
  - комментарий.
- Быстрый заказ автоматически попадает в `/admin/requests`.
- В заявке сохраняются:
  - товар;
  - ссылка на товар;
  - фото товара;
  - цена;
  - количество;
  - контакты клиента.
- Страница `/request` теперь умеет загружать несколько файлов / фото / чертежей.
- Добавлен bucket Supabase Storage `request-files`.
- Админка заявок переделана:
  - фильтр по типу заявки;
  - отдельная вкладка быстрых заказов;
  - статусы;
  - быстрые кнопки связи;
  - просмотр файлов;
  - фото товара в заявке.

## Что выполнить в Supabase

Выполнить свежий SQL:

```sql
database/supabase-schema.sql
```

Он добавит новые поля в таблицу `requests` и создаст bucket `request-files`.

## Новая переменная окружения

Опционально можно добавить:

```env
NEXT_PUBLIC_SUPABASE_REQUEST_FILES_BUCKET=request-files
```

Если не добавить, проект сам будет использовать `request-files`.
