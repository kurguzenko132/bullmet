# Bullmet — этап 5: отзывы, медиафайлы и баннеры

Что добавлено:
- Полноценный раздел `/admin/reviews`:
  - список отзывов;
  - фильтр по статусу;
  - поиск;
  - просмотр рейтинга;
  - редактирование текста отзыва;
  - скрыть/опубликовать;
  - удалить;
  - просмотр фото отзыва в большом окне.
- API отзывов:
  - `/api/admin/reviews`
  - `/api/admin/reviews/[id]`
- Полноценный раздел `/admin/media`:
  - медиатека сайта;
  - фото товаров;
  - фото отзывов;
  - фото баннеров;
  - ручная загрузка фото в Supabase Storage;
  - копирование ссылки;
  - просмотр изображения.
- API медиа:
  - `/api/admin/media`
- Новый раздел `/admin/banners`:
  - управление баннерами и акциями;
  - включение/выключение всех баннеров;
  - добавить/удалить баннер;
  - изменить текст, фото, ссылку, кнопку;
  - выбрать место показа;
  - задать даты начала и окончания.
- API баннеров:
  - `/api/admin/banners`
  - `/api/banners`
- На главной странице подключён компонент `HomePromoBanners`.
- Если баннеры включены в админке, они могут отображаться на главной.
- Добавлен SQL-файл `database/admin-reviews-media-banners.sql`.
- Проверка `npx tsc --noEmit` прошла успешно.

Важно:
- Для существующей базы выполнить `database/admin-reviews-media-banners.sql`.
- Если SQL из первого этапа ещё не выполнялся, сначала выполнить `database/admin-foundation-site-control.sql`, потому что там создаётся `admin_activity_log`.
