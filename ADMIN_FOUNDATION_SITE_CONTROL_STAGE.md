# Bullmet — этап 1: фундамент управления сайтом из админки

Что добавлено:
- Новый раздел `/admin/settings` для управления базовыми настройками сайта.
- Управление основными данными сайта: название, подпись логотипа, позиционирование, режим запуска.
- Управление контактами: телефон, email, адрес, время работы, Telegram, Instagram.
- Управление видимостью направлений:
  - Настенные часы
  - Садовая мебель
  - Мебель для дома в стиле лофт
  - Лазерная резка
  - Мелкий опт металлопроката
  - Гибка металла
- Управление пунктами меню: шапка, мобильная навигация, футер.
- SEO-заготовка: title, description, og image, index/noindex.
- Новый публичный API `/api/site-control`.
- Новый админский API `/api/admin/site-control`.
- Новый файл `lib/siteControl.ts` с дефолтными настройками и логикой merge.
- Header теперь может читать настройки меню и бренда через `/api/site-control`.
- Footer теперь читает настройки контактов и видимых направлений из Supabase.
- Добавлена таблица/миграция `admin_activity_log`.
- Добавлен SQL-файл `database/admin-foundation-site-control.sql`.
- Проверка `npx tsc --noEmit` прошла успешно.

Важно:
- Для существующей базы нужно выполнить SQL `database/admin-foundation-site-control.sql`.
- Если настройки ещё не сохранены в Supabase, сайт использует безопасные дефолтные значения.
- Следующий этап: подключить настройки главной страницы и управление блоками hero / переходы / популярные товары.
