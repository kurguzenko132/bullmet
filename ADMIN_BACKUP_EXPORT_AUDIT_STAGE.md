# Bullmet — этап 9: резервные копии, экспорт данных и технический аудит

Что добавлено:
- Новый раздел `/admin/backup`.
- Новый файл `lib/adminBackup.ts`.
- Новые API:
  - `/api/admin/backup`
  - `/api/admin/export`
- В админке появился центр резервных копий:
  - полная копия сайта JSON;
  - экспорт товаров;
  - экспорт заказов;
  - экспорт заявок;
  - экспорт отзывов;
  - экспорт пользователей;
  - экспорт настроек;
  - экспорт журнала действий.
- Поддерживаются форматы:
  - JSON;
  - CSV для табличных данных.
- Добавлен технический аудит:
  - Supabase;
  - robotsIndex;
  - видимые направления;
  - скрытость услуг;
  - категории;
  - товары;
  - фото товаров;
  - цены;
  - описания;
  - администраторы;
  - заказы;
  - заявки;
  - отзывы;
  - баннеры;
  - журнал действий.
- Добавлен общий скоринг готовности сайта.
- Добавлен чек-лист финальной проверки руками.
- Боковое меню теперь ведёт “Резервное копирование” на `/admin/backup`.
- Проверка `npx tsc --noEmit` прошла успешно.

Важно:
- Этот этап не требует отдельного SQL-файла.
- Экспорт работает на данных, которые уже есть в Supabase.
- Для защиты production API экспорта в будущем лучше дополнительно проверять роль на сервере.
