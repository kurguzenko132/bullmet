# Обновление: карточки каталога, кадрирование фото и админка

Что добавлено:

1. Карточки в каталоге
- рейтинг и количество отзывов;
- бейджи скидки, новинки и хита;
- старая цена и скидка;
- статус наличия;
- кнопка «Подробнее» + корзина;
- аккуратное отображение фото с настройками из админки.

2. Админка товаров
- drag-and-drop сортировка фото;
- выбор активного фото для настройки;
- режим отображения: показать целиком / заполнить;
- увеличение/уменьшение фото;
- позиция X/Y;
- отдельные настройки для каталога и карточки товара;
- применение настроек ко всем фото.

3. Мобильная карточка товара
- фиксированная нижняя панель покупки с ценой, корзиной и покупкой в 1 клик.

Если Supabase ругается на поле image_settings, выполнить SQL из:

database/product-image-settings-migration.sql
