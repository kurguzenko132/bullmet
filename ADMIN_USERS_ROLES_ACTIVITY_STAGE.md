# Bullmet — этап 6: журнал действий, пользователи и роли

Что добавлено:
- Новый раздел `/admin/users`:
  - список пользователей из `profiles`;
  - поиск;
  - фильтр по ролям;
  - изменение роли;
  - изменение имени;
  - изменение телефона;
  - статус active/blocked;
  - карточка доступа по роли.
- Новый раздел `/admin/roles`:
  - матрица ролей;
  - описание прав;
  - подготовка будущего разграничения интерфейса.
- Новый раздел `/admin/activity`:
  - журнал действий в админке;
  - фильтр по сущности;
  - поиск по действию, объекту, ID и payload;
  - просмотр деталей изменения.
- Новые API:
  - `/api/admin/users`
  - `/api/admin/users/[id]`
  - `/api/admin/activity`
- Добавлена библиотека `lib/adminPeople.ts`.
- Обновлено боковое меню админки:
  - Пользователи → `/admin/users`
  - Роли и права → `/admin/roles`
  - Журнал действий → `/admin/activity`
- Добавлен SQL-файл `database/admin-users-roles-activity.sql`.
- Расширены роли:
  - customer
  - admin
  - manager
  - content_manager
- Проверка `npx tsc --noEmit` прошла успешно.

Важно:
- Для существующей базы выполнить `database/admin-users-roles-activity.sql`.
- Этот этап готовит разграничение прав. Сейчас доступ в админку всё ещё защищён через `NEXT_PUBLIC_ADMIN_EMAIL / NEXT_PUBLIC_ADMIN_EMAILS`.
- Следующим этапом можно подключить реальные ограничения интерфейса по ролям.
