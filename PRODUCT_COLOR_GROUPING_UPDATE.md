# Обновление логики цветов товаров

Теперь цвета не создаются внутри одного товара как вложенные расцветки.

## Новая логика

1. Создайте отдельный товар для каждого цвета.
   - Например: `Часы — черные`
   - Потом: `Часы — белые`

2. В каждом товаре заполните блок:
   - `Группа модели / цвета`
   - `Название цвета`
   - `Цвет маркера`

3. Чтобы объединить товары, выберите у них одну и ту же группу.
   - Можно присоединить второй товар к первому.
   - Первый товар может быть без группы: если второй товар укажет группу первого товара, на странице первого товара тоже появится переключатель цветов.

## Как это работает на сайте

- В каталоге каждая цветовая карточка показывается отдельно.
- На странице товара показывается переключатель цветов.
- При выборе цвета меняются фото, цена, описание и характеристики выбранной карточки.

## Supabase

После обновления выполните свежий SQL:

`database/supabase-schema.sql`

Он добавляет поля:

- `color_group_id`
- `color_name`
- `color_hex`

Старое поле `variants` сохранено для совместимости, но новая логика его больше не использует.
