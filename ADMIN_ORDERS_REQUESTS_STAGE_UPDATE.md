# Bullmet — этап 3: админка заказов и заявок

Что добавлено:

- Полностью переработана страница `/admin/orders`.
- Полностью переработана страница `/admin/requests`.
- Добавлены реальные данные из Supabase:
  - `orders`;
  - `requests`.
- Добавлены интерактивные клиентские компоненты:
  - `AdminOrdersClient`;
  - `AdminRequestsClient`.
- Добавлены API routes для обновления статусов и заметок:
  - `PATCH /api/admin/orders/[id]`;
  - `PATCH /api/admin/requests/[id]`.
- Добавлены фильтры по статусам, поиск, статистика, просмотр деталей.
- Добавлены заметки администратора.
- Улучшена главная страница админки: теперь показывает количество заказов, заявок и оборот.
