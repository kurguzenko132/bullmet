# Bullmet — hotfix входа в личный кабинет

Что исправлено:

- `/login` по умолчанию теперь ведет в `/account`, если параметр `next` не задан.
- После успешного входа добавлен жесткий переход через `window.location.href`, чтобы Supabase-сессия точно сохранилась перед открытием `/account`.
- `/account` больше не делает мгновенный редирект на `/login`, если сессия сохраняется с небольшой задержкой.
- Добавлена повторная проверка сессии и `refreshSession`.
- Личный кабинет больше не должен ломаться из-за отсутствующей колонки `profiles.phone` в старой базе.
- Загрузка заказов, заявок, избранного и профиля стала безопасной: если одна таблица недоступна, кабинет все равно открывается.
