# Bullmet — этап 8: SEO, sitemap, категории и публичная видимость

Что добавлено:
- Новый раздел `/admin/categories`:
  - управление категориями часов;
  - управление скрытыми направлениями товаров;
  - управление скрытыми направлениями услуг;
  - включить/выключить категорию;
  - изменить название, slug, описание, изображение и SEO;
  - сортировка категорий.
- Новый файл `lib/catalogControl.ts`.
- Новые API:
  - `/api/admin/categories`
  - `/api/categories`
- Каталог `/catalog` теперь учитывает видимые категории из админки.
- Услуги `/services` теперь учитывают видимые направления из настроек сайта и категорий.
- Если услуги/направления скрыты, страница `/services` отдаёт `notFound`.
- `sitemap.ts` теперь динамический:
  - берёт товары из Supabase;
  - учитывает видимость категорий;
  - скрывает `/services`, если услуги не включены;
  - учитывает robotsIndex из SEO-настроек.
- `robots.ts` теперь динамический:
  - учитывает robotsIndex;
  - закрывает `/services`, если услуги скрыты;
  - закрывает `/admin`, `/account`, `/login`.
- `app/layout.tsx` теперь формирует базовые metadata из админских SEO-настроек.
- Обновлено боковое меню:
  - добавлен пункт `/admin/categories`.
- Обновлена матрица доступа:
  - content_manager получил доступ к категориям.
- Добавлен SQL-файл `database/admin-seo-categories-visibility.sql`.
- Проверка `npx tsc --noEmit` прошла успешно.

Важно:
- Для существующей базы выполнить `database/admin-seo-categories-visibility.sql`.
- Если SQL из первого этапа ещё не выполнялся, сначала выполнить `database/admin-foundation-site-control.sql`.
